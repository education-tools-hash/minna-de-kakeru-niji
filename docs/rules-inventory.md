# Rules テストの棚卸し（2026年11月2日夜）

対象：`tests/rules.test.js` の37件と、Nishio が指定した5項目。新規テストの追加は、この報告を受けて Nishio が判断する。

凡例：**担保**＝その性質を直接確かめるテストがある／**一部**＝一部の操作だけ確かめている／**なし**＝確かめるテストがない。
「一時確認」は、棚卸しの際にテストファイルへ加えずエミュレータで一度だけ試した結果（リポジトリには入れていない）。

## 1. 参加者が別の部屋の情報を読み書きできない

| 操作 | テスト | 状態 |
|---|---|---|
| 別の部屋のカウンタを書く・読む | A16 | 担保 |
| 別の部屋の meta・roles・requests を読む | なし（A3 は「未承認者は読めない」で同じ条件を確かめているが、別の部屋の参加者としては試していない） | 一部 |
| 別の部屋の役割・メンバー記録を書く | なし（A13 は自分の部屋で試している） | 一部 |

一時確認：別の部屋の meta・roles・requests の読み取り、役割・メンバー記録の書き込みは、すべて拒否された。

## 2. 教員が参加者のカウンタを変更・削除できない

| 操作 | テスト | 状態 |
|---|---|---|
| 教員がカウンタを＋1 する（set・update） | A19 | 担保 |
| 教員がカウンタを削除する | なし | **なし** |
| 教員がカウンタを減らす・0 に戻す | なし | **なし** |

一時確認：削除・減算・0 へのリセット（set・update とも）は、すべて拒否された。
補足：部屋全体の削除（終了操作）は教員に許可している（D3・D6、設計どおり）。このときカウンタも一緒に消える。

## まとめ

- テストがない操作：2 の削除・減算、3 の自分の役割の変更と meta の削除・期限の短縮、4 の期限切れ後・削除後の参加希望と期限切れ後の承認。
- これらは**一時確認ではすべて拒否された**。そのため、Rules の穴ではなく、テストで担保できていない状態である。
